## Game data

Some tables in `gori-online/*.h` (prices, catalogue rows, coordinates) were generated by the scripts in
`gori-online/tools/` from GTA V's own scripts and public wikis, so that the menus match GTA Online. They are
facts about the game, not game assets; GTA V and its trademarks belong to Rockstar Games / Take-Two
Interactive. This project is not affiliated with or endorsed by them.
